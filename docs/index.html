Lectura de esta sesión

Máximo observado: 1 persona frente a la barra.

La zona frente a barra acumuló 29.28 persona-segundos y el lado interior, 35.88. Son mediciones de este fragmento, con visitas parciales. No representan espera, ventas ni una jornada completa.

Qué investigar: si queremos medir espera, primero tendremos que ver la fila y marcar el inicio de atención. Esta escena y su permanencia observada no permiten decidir cuántas personas contratar. Se aplica un filtro de tamaño mínimo calibrado para este encuadre; no es una configuración universal.

Cafetería / Caso inicial

¿Se acumula gente al ordenar o al recoger?

Separa las áreas de pedido y entrega para saber dónde conviene mirar primero.

Señal que podemos observar
Ocupación, permanencia y movimiento entre zonas visibles.
Decisión que podría apoyar
Probar una señalización de recogida o un flujo distinto; comparar después.
Qué falta para decidir bien
Inicio de atención, pedidos y varias franjas representativas. La permanencia por sí sola no mide espera.

No calculamos ventas, compras, abandono o productividad individual a partir de presencia. Cada local necesita sus zonas, su contexto y su validación.

Primer piloto

Empieza por una pregunta.
No por diez cámaras.

Una cafetería de barra es nuestro primer caso de trabajo. La meta es demostrar una ayuda concreta al dueño antes de extenderla a otros giros.

Así se lee una sesión →
  1. Elige una decisión: por ejemplo, revisar acumulación frente a la barra.
  2. Prepara la vista: cámara fija, zona visible y permisos para usar el video. Define el área con el encargado.
  3. Valida una muestra: compara observaciones manuales y automáticas en distintos momentos.
  4. Prueba y compara: anota una acción y revisa períodos equivalentes antes de ampliarla.
